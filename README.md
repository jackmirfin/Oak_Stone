# Oak & Stone Renovations

A premium portfolio website for a fictional residential renovation company based in Northamptonshire, UK.

## Project Overview

This is a polished, production-quality demo website designed to showcase thoughtful residential renovations, extensions, and interior transformations. The design emphasizes craftsmanship, local expertise, and architectural quality without feeling like a generic trades template or ultra-luxury architecture firm.

## Design Philosophy

- **Premium but approachable**: High-quality aesthetic that feels expensive through simplicity
- **Local and trustworthy**: Emphasizes Northamptonshire roots and established craftsmanship
- **Editorial style**: Inspired by architecture and interiors publications
- **Generous spacing**: Negative space is used intentionally as a design element
- **Photography-focused**: Large, beautiful imagery of British residential architecture

## Color Palette

- Warm Ivory: `#F3EFE7` (Primary background)
- Deep Charcoal: `#171714` (Dark sections, text)
- Soft Stone: `#D8D0C3` (Accents, borders)
- Muted Bronze: `#B18A55` (Accent color only)
- Warm Grey: `#77736C` (Secondary text)

## Typography

- **Headings**: Cormorant Garamond (elegant editorial serif)
- **Body**: Inter (restrained sans-serif)
- **Style**: Large headings with tight line-height, generous body copy line-height

## Technical Features

- Semantic HTML5 structure
- CSS custom properties (design tokens)
- Responsive design (mobile, tablet, desktop)
- Native lazy loading for images
- Intersection Observer for scroll animations
- Accessible keyboard navigation
- Focus states for all interactive elements
- Prefers-reduced-motion support
- Contact form with modal interface
